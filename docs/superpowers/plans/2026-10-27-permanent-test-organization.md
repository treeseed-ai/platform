# Permanent test organization implementation plan

**Goal:** Put existing permanent coverage in four explicit tiers and make the development
strategy binding in every initialized owner and shared future setup.
**Architecture:** Independent owner suites and public package interfaces; Platform assembled
verification; shared instruction policy with executable owner layout checks.
**Tech stack:** Strict TypeScript classes, Bun/Node test runners, existing owner tooling and CI.
**Spec:** `../specs/2026-10-27-permanent-test-organization-design.md`
**Global constraints:** Preserve assertion bodies, timeouts, Keycloak identity, exact historical
artifacts, API committer policy, original checkouts and open issues. No Task 3D runtime work.
**Review focus:** Classification/discovery parity, support-only fixtures, immutable pin semantics,
CI partition completeness and genuinely failing layout checks.

1. Inventory tracked specifications, registrations, fixture/build paths and workflows in each
   owner. Save a checked old/new correspondence and baseline counts.
2. Establish failing policy/layout cases before changing enforcement. For the skill, exercise
   retrieval and pressure scenarios against old/new guidance and retain observed evidence.
3. Update AGENTS.md and release-workflow in all nine repositories. Add this design and owner
   testing guidance; add owner changelog entries. Commit documentation before implementation.
4. Move/split specifications into acceptance, regression, integration and unit. Extract shared
   setup only into support; keep assertion-bearing test methods in their tier. Preserve program
   fixture entrypoints through explicit path updates and maintain public test export names.
5. Rename Platform lasting assembled tests and helper programs by capability. Leave historical
   composition manifests and archives unchanged; update every current script/CI reference.
6. Add executable layout enforcement and adversarial regression cases. Include it in each
   applicable owner check/CI without copying owner runtime code into Platform or adding Agent
   application scaffolding. Verify future initialization's copied policy.
7. Run checks, builds, complete tier discovery and suites, partition read-back and assembled
   smoke where prerequisites exist. Compare registration/body inventory and report any real
   failure. Read all diffs, ensure no frozen artifact drift, open owner PRs against cordis and
   retain all issues open. Stop further Task 3D implementation pending cleanup review.
