# Coauthor a focused document

Apply the [project instructions](../../../AGENTS.md). Use supplied context, existing
material and accepted decisions before asking questions. Routine reference edits belong
to [documentation-writer](../documentation-writer/SKILL.md), not a compulsory workshop.

Establish the reader, the decision or task the document supports, relevant constraints
and material gaps. Gather authorized context with available tools. Ask focused questions
only where the answer changes the document; do not require a fixed question count,
option quota or separate approval for each section.

Draft the smallest complete document in the established format and location. Distinguish
requirements, proposals, assumptions and open decisions. Link canonical policy instead
of repeating it. Review consequential structure with the user when it is genuinely
unsettled; preserve approval already supplied for the described work.

Iterate on specific feedback. The user may edit directly; inspect and preserve those
changes. Check whether a reader can act from the document without the conversation.
For a consequential ambiguous document, a fresh reader review may help when delegation
is authorized and available. Direct reader walkthroughs are a fallback; neither requires
a particular model or tool. Record the actual gaps and fix them without reopening scope.

Verify facts, references, consistency and intended vs delivered claims. Report the
artifact, review evidence and unresolved decisions. Do not claim reader testing occurred
unless it did. Saving or publishing to an external destination requires authorization
for that destination; drafting alone does not authorize distribution.
